# HermesDB

NoSQL key-value база данных на C++. Смотрите также https://github.com/POAL484/MnemosyneDB/.

> **Гермес** — в древнегреческой мифологии бог-вестник и посланник Олимпа. Его крылатые сандалии позволяли преодолевать любые расстояния в мгновение ока, а кадуцей — жезл с переплетёнными змеями — символизировал обмен и связь между мирами. Он был проводником между богами и смертными, доставляя послания быстро и без потерь. Так же этот проект стремится быть быстрым и надёжным посредником между хранилищем и приложением.

## API

## /new (метод: GET)
Создать нового пользователя и получить его uuid.
* **Ответ**:
  * **Код**: 200
  * **Контент**: JSON объект вида: `{ "uuid": ... }`

Все действия с хранилищем разрешаются только при передаче корректного uuid пользователя. Иначе вернется код 403 с телом `{"error": "Unknown user uuid"}`.

## /?uuid={uuid} (метод: GET)
Получить значение по ключу. Если такого нет, вернуть null. 
* **Тело запроса**: JSON объект вида `{ "key": ... }`
* **Ответ**:
  * **Код**: 200
  * **Контент**: JSON объект вида: `{ "value": ... }`

## /?uuid={uuid} (метод: POST)
Установить значение по ключу.
* **Тело запроса**: JSON объект вида `{ "key": ..., "value": ... }`
* **Ответ**:
  * **Код**: 200

## /?uuid={uuid} (метод: DELETE)
Удалить ключ.
* **Тело запроса**: JSON объект вида `{ "key": ... }`
* **Ответ**:
  * **Код**: 200
